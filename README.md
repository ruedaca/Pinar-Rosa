# Pinar Rosa

Landing page y plataforma web para Pinar Rosa, desarrollada con Next.js, React y Tailwind CSS.

---

## 🚀 Requisitos previos

Asegurate de tener instalado:

- **Node.js** (versión 18.x o superior recomendada)
- **npm**, **yarn** o **pnpm**

---

## 🛠️ Instalación y Setup Local

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/ruedaca/Pinar-Rosa.git](https://github.com/ruedaca/Pinar-Rosa.git)
   cd Pinar-Rosa/pinar-rosa
   ```
